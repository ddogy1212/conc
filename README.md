# CONC 집중 스위치

갤럭시 홈 화면 1×1 집중 위젯. 최초 설정 후 위젯 한 번 탭으로 30분 집중하며, 선택한 앱의 화면을 Android 접근성 서비스로 가립니다. 중도 취소 버튼은 없습니다.

설치용 APK는 GitHub Actions가 빌드 완료 시 `downloads/conc-debug.apk`에 업로드합니다. 접근성 권한은 사용자가 직접 활성화해야 합니다. 시스템 설정에서 서비스를 끄거나 앱을 삭제하는 것까지는 막을 수 없으며, 긴급 전화와 필수 시스템 앱은 차단 대상에서 제외합니다.

사진 설정: 앱에서 사진을 고르면 위젯 배경으로 사용하며, 선택한 사진으로 별도의 홈 화면 바로가기 아이콘을 추가할 수도 있습니다. 안드로이드 특성상 기본 앱 런처 아이콘을 임의 사진으로 직접 교체하지는 못합니다.
